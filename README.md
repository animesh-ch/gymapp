# Gymapp

A workout log for Android and iOS. Search a built-in exercise library, record repetitions, add your own exercises, and keep everything on the device. Export and import that data as one JSON file.

## Run

```bash
npm install
npm start
```

Then press `a` for Android, `i` for iOS, or `w` to open the web build. iOS compilation needs Xcode on a Mac. The web build uses the same screens and stores data in the browser's local storage so the flow can be tried without a phone.

```bash
npm test
npm run typecheck
```

## What is stored

Built-in exercises ship with the app and keep stable ids such as `bench-press`. Custom exercises and rep entries are saved on the device. On Android and iOS that is a JSON file in the app documents folder, with GIF files beside it. A backup looks like this:

```json
{
  "version": 1,
  "exportedAt": "2026-10-03T16:50:00.000Z",
  "exercises": [
    {
      "id": "7c1e",
      "name": "Nordic curl",
      "muscles": ["hamstrings"],
      "category": "legs",
      "gifBase64": null
    }
  ],
  "records": [
    {
      "id": "a91b",
      "exerciseId": "bench-press",
      "reps": 8,
      "recordedAt": "2026-10-03T16:40:00.000Z"
    }
  ]
}
```

Import replaces custom exercises and rep history. The built-in library is unchanged. An invalid file leaves the device data as it is.

The bundled GIFs are schematic demonstrations generated by `scripts/generate-exercise-gifs.py`, so the library is usable without shipping someone else's footage. Replace `assets/exercises/<id>.gif` with your own GIF of the same name to change a demonstration.
